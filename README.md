# Frontend-Angular

Este projeto é um exemplo de aplicação CRUD (Create, Read, Update, Delete) utilizando Angular para o frontend e Node.js com Express para o backend. A aplicação gerencia uma lista de cursos, permitindo que os usuários visualizem, adicionem, editem e excluam cursos.

# Tecnologias Utilizadas
- Angular: Framework para construção de aplicações web.
- Node.js: Ambiente de execução para JavaScript no servidor.
- Express: Framework para construção de APIs RESTful.
